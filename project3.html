Project Reflection

The aim of this project was to create an information display that showed useful information such as the date, time and weather.

I decided to make my design with a TRON theme which drove the choices I made in the design of the project, for example, the complex border around the screen that had a loading animation when the arduino was connected to the computer. There were many challenges and setbacks I faced along the way to completing this project, such as the tedious nature of selecting colours and finding specific positions on the screen, i solved this problem by implementing brute force and trial and error, which while working to an extent, it sucked up a large amount of time and may not have been the most effective method.

Another challenge that I faced was my desire to include an external font into my design, this led me to learn more about fonts, how they work, and how to implement them, unfortunately the verdict i reached was that implementation of a custom font would require too much storage on the arduino to be worthwhile.

By far the biggest setback I faced was the failure of my computers USB port on the last week of the assignment time, this meant that I was completely unable to render and view what my code was doing and made troubleshooting for errors extremely difficult, this meant that i was flying blind because I couldn't check what my actual product looked like.

I am most proud of the layout and design of my display, which featured a custom ‘loading’ sequence that triggers when the python script to send data to the arduino is triggered. Overall, this project led me to learn a lot more about coding, formatting, designing, planning, and troubleshooting, even if it was not always successful, if i was going to do this project again i would better plan my time, find more shortcuts to be more efficient with simple repetitive tasks such as finding colours and plotting shapes.
